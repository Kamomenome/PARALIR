# PARALIR（ver 1.33）

写真 1 枚から「別の世界」の絵を作る、ブラウザで動くアプリです。写真全体を大きく崩して元の写真の一部を主題として残したり、
写真はそのままに一部だけを長方形で組み替えたりします。無料で、誰でも使えます（[MIT ライセンス](LICENSE)）。

## プライバシー

- 写真は**あなたの PC の中だけ**で処理します。人物や物を見分ける AI も、PC の中で動きます
- 写真・作った絵・AI の結果は、どこにも送りません。外への通信は、アプリとブラウザの両方で止めています
- アカウントも登録も要りません。データを保存するのは、あなたが「書き出す」「レシピを保存」を押したときに、あなたの PC へだけです

## 使い方

1. https://kamomenome.github.io/PARALIR/ を開きます
2. 絵の場所をクリックして写真（JPEG・PNG）を選ぶか、写真をドラッグして置きます。まず元の写真が出ます
3. 主役を決めたいときは、元の写真の上をドラッグして囲みます（Shift を押しながらで囲みを足せます）。輪郭は AI が合わせ、囲んだ範囲がうっすら色付きで出ます
4. 「反映」を押すか「モード」を選ぶと、絵になります（物の複製・被写体の解体・矩形の組み替え・入れ子・主題。最初の写真では 1 つ選ばれた状態で始まります）
5. スライダー（背景・主役）で整えます。出てくるのは、そのモードで効くものだけです。「光の形」で、輪の光とまっすぐな光の間を動かせます。囲み直すときは「元の画像を表示」にします
6. 「ひとつ戻す」（Ctrl+Z）で直前の変更を戻せます。「元の画像を表示」で元の写真と見比べられます
7. 「画像を書き出す」で PNG を保存します（写真と同じ縦横比、長い辺 2400px）。「レシピを保存」で設定を残すと、同じ写真から同じ絵に戻せます（古い版で保存したレシピも開けます）

**対応環境**: Windows 11 のデスクトップ版 Google Chrome / Microsoft Edge（スマホは対象外です）

**絵の作り方**: 絵を作る部分（崩す・組み替える・複製する・光を描く）は、決まった計算だけで行っています。画像を生成する AI は使っていません。
同じ写真と設定からは、いつも同じ絵になります。

**AI について**: AI は、写真の中の人物や物の位置と輪郭を見分けるためだけに使います（Google の MediaPipe のモデル。AI が使えないときは写真から推定して描きます）。モデルの説明書では、監視や個人の識別、命に関わる判断に使うことは想定外とされています。
PARALIR は絵を作るためだけに使います。詳しくは画面の「このアプリについて」と [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
