# PARALIR（ver 1.27）

写真 1 枚から「別の世界」の絵を作る、ブラウザで動くアプリです。写真全体を大きく崩して元の写真の一部を主題として残したり、
写真はそのままに一部だけを長方形で組み替えたりします。無料で、誰でも使えます（[MIT ライセンス](LICENSE)）。

## プライバシー

- 写真は**あなたの PC の中だけ**で処理します。人物や物を見分ける AI も、PC の中で動きます
- 写真・作った絵・AI の結果は、どこにも送りません。外への通信は、アプリとブラウザの両方で止めています
- アカウントも登録も要りません。データを保存するのは、あなたが「書き出す」「レシピを保存」を押したときに、あなたの PC へだけです

## 使い方

1. https://kamomenome.github.io/PARALIR/ を開きます
2. 絵の場所をクリックして写真（JPEG・PNG）を選ぶか、写真をドラッグして置きます
3. 「別の世界」（Space キー）で、別の案を次々に出します。「ひとつ戻す」（Ctrl+Z）で 1 つ前に戻ります
4. 「世界」で描き方を固定できます（おまかせ・物の複製・闇と光・被写体の解体・門・矩形の組み替え・自分で埋める・主題）
5. 主題にしたいところがあれば、絵の上をドラッグしてざっくり囲みます。輪郭は AI が合わせます
6. スライダーで光・大きさ・数・暗さを整え、「2400×1800 で書き出す」で PNG を保存します
7. 「レシピを保存」で作品の設定を残せます。同じ写真を入れてからレシピを読み込むと、同じ絵に戻ります（古い版で保存したレシピも開けます）

**対応環境**: Windows 11 のデスクトップ版 Google Chrome / Microsoft Edge（スマホは対象外です）

**AI について**: Google の MediaPipe のモデルを使っています。モデルの説明書では、監視や個人の識別、命に関わる判断に使うことは想定外とされています。
PARALIR は絵を作るためだけに使います。詳しくは画面の「詳しい設定 → このアプリについて」と [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
