# Feature Specification: ロゴとアイコン（版 1.30 に含める）

**Feature Branch**: `014-logo`
**Created**: 2026-10-13
**Status**: Draft
**Input**: 利用者「out にロゴデザイン入れたので反映して　画面内と、アイコンね」（`out/PARALIRロゴデザイン案提案.zip`）。
「（このアプリについての文に）絵の編集自体には AI を使っていない旨は明記した方がよくない？こだわりだろ？」。言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（ロゴ・アイコン）。

## Requirements *(mandatory)*

- **FR-1401**: パネルの見出しの文字「PARALIR」を、ロゴの画像（`paralir-logo-1x.png`）に替える。高さ 32px 前後、版（ver）はロゴの横に今までどおり出す。
  画面読み上げのために見出しの文字としての「PARALIR」は残す（画像の代わりの文字・見えない文字）
- **FR-1402**: ブラウザのタブとブックマークのアイコンを、アイコンの画像（16・32・48px）にする。iPhone などのホーム画面用に 180px も指定する。512px はリポジトリに置く（今後の PWA 用）
- **FR-1403**: ロゴとアイコンは利用者の作品として `public/brand/` と `src/ui/brand/` に置き、公開してよい画像として扱う（実在の写真ではない。009 FR-922 の「画像は試験用だけ」の決まりに、ブランド画像を足す）
- **FR-1405**: 「このアプリについて」と README に、次を明記する: 絵を作る部分（崩す・組み替える・複製する・光を描く）は決まった計算だけで行い、画像を生成する AI は使っていない。
  同じ写真と設定からは同じ絵になる。AI は写真の中の人物や物の位置と輪郭を見分けるためだけに使う（AI が使えないときは写真から推定して描く）
- **FR-1404**: 絵・操作は変えない

## Success Criteria *(mandatory)*

- **SC-1401**: e2e: 見出しにロゴの画像が読み込まれて見え（幅 > 0）、見出しの文字は「PARALIR」のまま。ページのアイコンの指定が 16・32・48・180px ある
- **SC-1403**（FR-1405）: e2e: 「このアプリについて」に「画像を生成する AI は使っていません」と、AI を使う目的（位置と輪郭を見分ける）が出る
- **SC-1402**: Web 版のビルドにアイコンとロゴのファイルがある。git が管理する画像は試験用の絵とブランド画像だけ
