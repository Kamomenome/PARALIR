# Feature Specification: 第三者が使えるアプリと、直しやすく足しやすい作り（版 1.27）

**Feature Branch**: `009-open-and-extensible`
**Created**: 2026-10-13
**Status**: Draft
**Input**: 利用者「金はとらないけど第三者が使っても問題ないようにはしたい　そのつもりで　後は保守性や、機能拡張性」
→ 決定（[decision.md](decision.md)）: ライセンス MIT・Web ページで公開・ソース公開・バックエンドは作らない・古い作品は 1 つの URL で古い描き方を必要なときだけ読む（「あぐりー」）
→「拡張性考えても部品ごとにソース作らないの？計算部分のアルゴリズムだけとか」
→「今使ってない古いコードや機能があればそれも整理したほうがいいね」
→（公開前の確認で）「写真とかは消した方がいいんじゃない？」。
言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（第三者が使っても問題ない・Web 版／ダウンロード版・エンジン・部品ごとのソース・バックエンド）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 誰でも URL を開くだけで使え、何をしてよいかが分かる (Priority: P1)

第三者が公開された URL を開くと、paraller が使える。画面の「このアプリについて」で、ライセンス（MIT）、使っている部品のライセンス、AI の用途の注意、写真が外へ出ないことが読める。

### User Story 2 - 古い版で保存した作品も、同じ URL で開ける (Priority: P1)

描き方の版が上がったあとでも、古い版で保存したレシピを読み込むと、その版の描き方を読み込んで同じ絵を描く。

### User Story 3 - 開発者が世界を 1 つ足すとき、触るのはその世界のフォルダと登録 1 行 (Priority: P2)

### User Story 4 - 開発者が迷わない（境界・型・小さなファイル・自動テスト） (Priority: P2)

## Requirements *(mandatory)*

### 部品ごとのソース（拡張性）

- **FR-901**: 計算（組み立てと描画）を `src/engine/` に置く。どの版でも使う土台は `engine/common/`、描き方の版 1 つ分は `engine/space-v2/`（世界どうしの共有部品は `shared/`、世界ごとに `worlds/<名前>/`）
- **FR-902**: 世界は「登録」で足す。1 つの世界は、名前（画面の表示と一行の説明）・出やすさ・組み立て・描き方を自分のフォルダで持ち、版の入口の一覧に 1 行で登録する。
  世界の一覧・画面の選択肢・レシピの検証・テストは登録から作る（手で並べた一覧を持たない）
- **FR-903**: 境界をテストで守る: `engine` は `app`・`ui`・`worker`・`ai` と DOM（`document`・`window`）を使わない

### 古い作品の互換（エンジンの版）

- **FR-904**: エンジンの一覧（`engine/engines.ts`）は、各エンジンの版の組（`algorithms`）と、読み込み方（必要なときだけ読む）を持つ。今のエンジンはいつも読む
- **FR-905**: レシピの `algorithms` に合うエンジンが一覧にあれば、それで組み立てて描く（画面でも Worker でも）。なければ今までどおり理由と保存した版を出して断る
- **FR-906**: 世界の版を上げる手順（今のエンジンを凍結して一覧に加えてから、新しい版を作る）を `CONTRIBUTING.md` に書く

### 保守性

- **FR-907**: Worker とのやりとりのメッセージに型を付け、1 つのファイルで定める（画面側と Worker 側が同じ型を使う）
- **FR-908**: 使っていない帯分割の仕組みを除く（どのエンジンも 1 枚まるごと描く）
- **FR-909**: 画面の配線（`ui/main.ts`）を、写真の入力・囲み・レシピ・書き出し・キーボードに分ける
- **FR-910**: 使っていない変数・引数を型チェックで見つける（`noUnusedLocals`・`noUnusedParameters`。新しい道具は足さない）
- **FR-921**: 使っていない古いコード・機能・道具・資料を整理する。どこからも読み込まれていない書き出し（export）とファイルを道具（`tools/unused.ts`）で洗い出し、
  利用者に一覧を見せてから消す。テストだけが使う書き出しは、テストの理由があれば残す

### 第三者が使える

- **FR-911**: アプリのライセンスを MIT にする（`LICENSE`）
- **FR-912**: 使っている部品のライセンス表示（`THIRD_PARTY_NOTICES.md`）を道具で作る: MediaPipe（Apache-2.0、Lucent の告知を含む）、AI モデル 3 つ（Apache-2.0、Google、モデルカードの URL）、
  wasm に組み込まれた部品（OpenCV・Eigen など、出所）、temporal-polyfill・temporal-utils（MIT）、ビルドで入る小さな補助（Vite、MIT）
- **FR-913**: 画面の「このアプリについて」（詳しい設定の中）で、版と commit・MIT・プライバシー（写真は端末の外へ出ない。外への通信はブラウザでも止めている）・
  AI の用途の注意（監視や個人の識別、命に関わる判断には使わない）・部品のライセンス表示を読める
- **FR-914**: 利用者向けの README（何ができるか・使い方・プライバシー・対応環境: Windows 11 のデスクトップ版 Chrome / Edge）と、開発者向けの `CONTRIBUTING.md`（世界の足し方・版の上げ方・テスト）

### Web 公開

- **FR-915**: 主なビルドを Web 版にする（`npm run build` → `dist/`、複数ファイル、相対パス）。AI モデルと wasm は別のファイルにし、ブラウザのキャッシュで版をまたいで使い回す
- **FR-916**: ダウンロード版（HTML 1 枚）は `npm run build:single` → `dist-single/index.html` で残す
- **FR-917**: どちらのビルドにも CSP を入れる（Web 版は同じ場所からの読み込みだけを許す）。外への通信 0 件を e2e で確かめる
- **FR-918**: GitHub Actions を用意する: push のたびに型チェック・Vitest・ビルド・Playwright、main への push で Web 版を GitHub Pages に公開。
  リモートの作成と公開の有効化は利用者が行う（このリポジトリにはまだリモートがない）

### 公開前の写真の除去

- **FR-922**: 実在の写真と、そこから作った絵をリポジトリに入れない。テストは道具で作った合成画像（`tools/make-scene.ts` → `tests/fixtures/images/scene.png`）を使い、
  世界の画素の記録も合成画像で取り直す。気に入った Phase 9 の 16 枚の再現テストは、元の写真が手元（`samples/reference/`、git の対象外）にあるときだけ流す
- **FR-923**: 公開する履歴にも写真を含めない（方法は decision.md）

### 変えないもの

- **FR-919**: 描かれる絵（Phase 9 の 16 枚、世界の 43 枚）・レシピの形式・写真を外へ出さないことは変えない。版は 1.27

## Success Criteria *(mandatory)*

- **SC-901**（FR-901〜FR-903）: 境界のテストが通る。世界の一覧が登録から作られる。画素の記録がすべて一致する
- **SC-902**（FR-904〜FR-905）: unit: 一覧に加えた別のエンジン（試験用）の版の組を持つレシピは、そのエンジンで組み立てて描かれる。一覧にない版は断られる
- **SC-907**（FR-921）: `tools/unused.ts` が「使われていない書き出し・ファイル」を 0 件と報告する（残すものは理由つきの許可リスト）
- **SC-908**（FR-922）: git が管理する画像は、道具で作った試験用の絵だけ（unit で一覧と照らす）。写真がなくても全テストが通る（Phase 9 の再現だけが飛ばされる）
- **SC-903**（FR-907〜FR-910）: 型チェック（未使用の検出つき）が通る。`main.ts` が配線だけになる（目安 120 行以下）
- **SC-904**（FR-911〜FR-914）: `LICENSE`・`THIRD_PARTY_NOTICES.md`・`CONTRIBUTING.md` がある。e2e: 「このアプリについて」に MIT・Apache-2.0・プライバシー・用途の注意が出る。ビルドに表示が含まれる
- **SC-905**（FR-915〜FR-917）: e2e: Web 版を静的に配信して開き、写真から絵が出て AI が動き、外への通信 0 件、CSP の違反なし（MediaPipe の利用統計の送信先を除く）。ダウンロード版も同じ
- **SC-906**（FR-918, FR-919）: ワークフローのファイルがある。既存のテストがすべて通る。版は 1.27

## Out of Scope

- バックエンド（サーバー）・アカウント・作品の共有（decision.md）
- npm パッケージへの切り出し（フォルダとテストで境界を守る。ほかで使いたくなったら切り出す）
- スマホ（007 のとおり）
