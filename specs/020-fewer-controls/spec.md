# Feature Specification: レシピとスライダーを減らし、変貌するスライダーへ（版 1.34 に含める）

**Feature Branch**: `020-fewer-controls`
**Created**: 2026-10-14
**Status**: Draft
**Input**: 利用者「レシピはそもそも余計な機能なので削減」「じゃあいいや今のままで　あとレシピは削除　あと写真に合わせる強さは削除　光と背景の暗さも削除　長方形の数とかはあってもいいけど、期待するのは、スライダー動かすとダイナミックに変貌する感じ　大きさがとかじゃない」。言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（レシピ・写真に合わせる強さ・光の強さ・背景の暗さ・ダイナミックに変貌する・計算をサーバーに）。

## 調べたこと

- レシピは保存（`recipePanel`・`recipeActions`・`engine/recipe.ts`）と読み込み（`app/recipeLoad.ts`・`applySpaceRecipe`）。凍結エンジン（`engine/frozen/space-v2-1〜4`）は、古いレシピを開くためだけにある
- 写真に合わせる強さ（featureInfluence）・光の強さ（light）・背景の暗さ（darkness）は描き方の中で係数として使っている。値を今までの初期値に固定すれば、画素は変わらない

## Requirements *(mandatory)*

- **FR-2001**: レシピの保存と読み込みを、画面とコードから削除する（ボタン・案内・検査・読み込みの処理・テスト）
- **FR-2002**: 凍結エンジン space-v2-1〜4 と、エンジンを選ぶ仕組み（版からエンジンを探す・あとから読み込む）を削除する。描き方は今の 1 つだけ。描き方を変えるときの「凍結してから版を上げる」手順もなくし、画素の記録を記録し直すだけにする（CONTRIBUTING.md・docs/REPRODUCIBILITY.md）
- **FR-2003**: スライダー「写真に合わせる強さ」「光の強さ」「背景の暗さ」を削除する。描き方の中では今までの初期値（0.75・0.5・0.5）を定数として使い、画素は変えない
- **FR-2004**: 残すスライダーは「光の形」「主役の大きさ」「長方形の数」。見出し（背景・主役）は、出るものがあるときだけ
- **FR-2005**: 同じ写真・作品日時・設定から同じ絵になること（共鳴パターン化）は変えない。画素の記録（world-hashes・Phase 9）は変わらない
- **FR-2006**（次の段階、比較画像で決める）: モードごとに「動かすとダイナミックに変貌する」スライダーの案を作り、0・0.5・1 の比較画像で利用者に選んでもらう。主役の大きさは、選んだ案と入れ替えるかをそこで決める

## Success Criteria *(mandatory)*

- **SC-2001**（FR-2001）: e2e: 「レシピを保存」「レシピを読み込む」がない。unit: レシピのコード（`toSpaceRecipe` など）がない（未使用コードの検査が 0 件）
- **SC-2002**（FR-2002）: 凍結エンジンのフォルダがなく、作品は今のエンジンで描く
- **SC-2003**（FR-2003・2004）: e2e: どのモードでも「写真に合わせる強さ」「光の強さ」「背景の暗さ」が出ない。物の複製は「光の形」「主役の大きさ」、矩形の組み替えは「長方形の数」
- **SC-2004**（FR-2005）: 画素の記録がすべて通る
- **SC-2005**: 既存のテスト（消した機能のものを除く）がすべて通る
