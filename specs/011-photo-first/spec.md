# Feature Specification: 写真を入れた直後は元の写真を出す（版 1.28）

**Feature Branch**: `011-photo-first`
**Created**: 2026-10-13
**Status**: Draft
**Input**: 利用者「写真入れたときにいきなり変化するとわかりづらいのでこちらが操作するまでは普通の画像をだしておけ　画像入れ込めたかどうかも分かりづらいので」。
言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（普通の画像）。

## Requirements *(mandatory)*

- **FR-1101**: 写真を入れたら、絵の場所には**入れた写真そのもの**を出す（世界と同じ 4:3 の枠。囲みの位置が世界の絵と合う）。絵の下に「元の写真です。「別の世界」（Space）を押すと別の世界になります」と出す
- **FR-1102**: 利用者が操作したら世界を出す: 「別の世界」・Space・スライダー・世界の選択・囲み・作品日時・レシピの読み込み。
  元の写真のときの「別の世界」は別案を進めずに今の別案（別案 0）の世界を出す（別案 0 を飛ばさない）。2 回目からは今までどおり別案を進める
- **FR-1103**: 元の写真を出している間、「書き出す」と「レシピを保存」は押せない（何を保存するかが画面と食い違わないように）
- **FR-1105**: 囲みの白い線だけを隠せる（利用者「白い囲みだけ消して変更はリセットしない方法は？」）。囲みの横に「線を隠す」／「線を出す」を置き、線の表示だけを切り替える（絵は変わらない）。
  囲みの効果を取り消すボタンは、紛らわしくないよう「囲みを消す」から「囲みを解除」に名前を変える。線は画面に重ねているだけで、書き出しの PNG には入らない（今までどおり）
- **FR-1106**: 「別の世界」をクリックした直後（ボタンに選択枠があるとき）でも Ctrl+Z で「ひとつ戻す」が効く（実装中に見つけた不具合。ボタンには自分の取り消しがない）
- **FR-1104**: 世界の絵・レシピ・別案の番号の付け方は変えない（同じ写真・設定で同じ絵）。版は 1.28

## Success Criteria *(mandatory)*

- **SC-1101**: e2e: 写真を入れると元の写真が出る（絵の中央の色が写真の中央とほぼ同じ）、案内が出る、書き出しとレシピの保存は押せない
- **SC-1102**: e2e: Space で世界が出て別案は 0 のまま、もう一度 Space で別案 1。スライダーを動かしても世界が出る。囲みを描いても世界が出る
- **SC-1104**（FR-1105）: e2e: 囲んだあと「線を隠す」で線が消え、絵は変わらない。「線を出す」で戻る。「囲みを解除」で囲みの効果が取り消される
- **SC-1103**: 既存のテストがすべて通る
