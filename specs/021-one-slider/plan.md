# Plan: スライダーは「変貌」1 本、光の形はカオスに

## 変貌の値（FR-2101〜2104）

- `SpaceControls` を `{ morph: number }`（最初 0.5）にする。光の形・主役の大きさ・長方形の数は `FIXED_LOOK` に足す（size 0.5・count 0.5、光の形は写真から決まった形）。光の形を混ぜる仕組み（`renderShapedAtmosphere`・`shapeVariants`・`mixInto`）は使わなくなるので消す
- 0〜0.5（広がり）: `renderWorld` の最後で、0.5 の絵と元の写真（`framePhoto`）を画素ごとに混ぜる。混ぜる量は「広がりの場」で決める
  - 広がりの場 = seed から決めた入り組んだノイズ（fbm）と、写真の明るさをぼかしたものを合わせた 0〜1 の値
  - 主役の外は u = 変貌 / 0.5 が場の値を越えた所から、主役は u が 0.4 を越えてから遅れて変わる。境目は少しだけぼかす（なめらかに切り替わる幅を持たせる）
  - ノイズの種は組み立てのときに 1 回だけ引く（新しい名前の流れ `morph/seed`。今までの乱数は変わらない）
- 0.5〜1（激しさ c = 2 × (変貌 − 0.5)）: 各モードの値に c を掛ける。c = 0 では今までと同じ計算になるようにする（画素の記録が同じ）
  - 物の複製: 1 つずつの回転 × (1 + 6c)、位置の散らばり（新しい流れ `copies/scatter`）× c、数 + 12c（最大 24）
  - 被写体の解体: explode × (1 + 3c)、spin・lift × (1 + 4c)、型から外れる割合 → 1、破片 + 4c（最大 8）
  - 矩形の組み替え・主題: 長方形の数 0.5 + 0.5c（019 の幅）、ずれ・入れ替え・拡大・抜け × (1 + 2c)、長方形の位置のずれ × (1 + 4c)
  - 入れ子: 並べる数・渦の回り × (1 + 2c)
- 画面: スライダー 1 本（「変貌」、見出しなし）。モードの選択は残す

## 光の形（FR-2105）

- `lightShape()` に形を足す（候補: 渦 `swirl`、ひび割れの筋 `cracks`、炎のように揺らぐ帯 `flame`、散らばった光源 `scatter`）。選ぶ割合と足りない値は新しい流れ（`atmos/shape2`）から引く
- 比較画像で選んでもらってから残す形を決め、`atmosphere-v3`・主題の版を上げて画素を記録し直す

## 調べたこと（research）

- 0.5 の絵を今と同じにすれば、気に入ってもらった絵（画素の記録）はそのまま残る。広がりと激しさは、どちらも「0.5 のときは何もしない」形で足せる
- 混ぜる場は画素ごとの計算で、乱数の位置を変えない。新しい乱数は新しい名前の流れから引くので、今の値は変わらない（docs/REPRODUCIBILITY.md の 3）
- 依存は足さない
