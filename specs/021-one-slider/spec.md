# Feature Specification: スライダーは「変貌」1 本、光の形はカオスに（版 1.34 に含める）

**Feature Branch**: `021-one-slider`
**Created**: 2026-10-14
**Status**: Draft
**Input**: 利用者「（変貌スライダーの方向は）OK」「（光の形は）ほかにある？カオスがいいね　直線と円しかないのは微妙」「（背景 × 主役の組み合わせは）いらないかもしれん」「できるだけシンプルにしたい　囲った部分とそうでない部分を一つのスライダで弄るとなんか変貌していく感じで」「スライダは1個でいいよもはや　あとは選べない感じで」。モードは残す（同日の回答）。言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（変貌・カオス・背景 × 主役の組み合わせ）。

## 調べたこと

- 今のスライダーは光の形・主役の大きさ・長方形の数。どれも係数で、乱数の位置を変えない
- 物の複製はコピーの並び（環・扇・列・格子・螺旋）とその数・小さな回転、被写体の解体は破片の数・飛び方（explode）・回り方（spin・lift）・型から外れる割合、矩形の組み替えと主題は長方形の数・ずれ・入れ替え・拡大・抜け、入れ子は並べる数と渦の回りで、崩れ方が決まる
- 光の形は輪・端からの光・帯の 3 つ（`lightShapeFrom`）。背景（物の複製・被写体の解体）と主題の下地で使う

## Requirements *(mandatory)*

### 変貌（1 本だけのスライダー）

- **FR-2101**: 画面のスライダーは「変貌」1 本だけにする（0〜1、最初は 0.5）。光の形・主役の大きさ・長方形の数は画面とコードから削除し、描き方の中では今までの初期値を使う（光の形は写真から決まった形）
- **FR-2102**: 0 から 0.5 では、元の写真の上に別の世界が広がっていく。0 は元の写真のまま、0.5 は今の絵のまま。囲みの外（主役でない所）が先に、主役（囲んだ所。囲みがなければ推定の主役）があとから変わる。境目はまっすぐではなく、写真の明るさと seed から決まる入り組んだ形で進む
- **FR-2103**: 0.5 から 1 では、そのモードの崩れ方が激しくなる。物の複製: コピーが増え、散らばり、回る。被写体の解体: 破片が遠くへ飛び、回り、型から外れる。矩形の組み替えと主題: 長方形が増え、大きくずれ、入れ替わり、抜ける。入れ子: 並べる数が増え、渦が回る
- **FR-2104**: どの値も写真・作品日時・変貌の値から決まる（同じ条件なら同じ絵）。0.5 の絵は今の画素の記録と同じ

### 光の形（カオス）

- **FR-2105**: 光の形に、直線と円でない形を足す（渦・ひび割れのように広がる筋・揺らぐ炎のような光・散らばった光源など、候補は比較画像で選ぶ）。形は写真と作品日時から決まり、選べない。足した形が出るので背景と主題の版を上げ、画素を記録し直す

### やめること

- **FR-2106**: 背景 × 主役の組み合わせ（013B T1305〜T1308）はやめる

### 比較画像

- **FR-2107**: 変貌はモードごとに 0・0.25・0.5・0.75・1、光の形は候補ごとに、写真 4 枚で比較画像を作る（`out/021/`）。利用者が見て決め、decision.md に書く

## Success Criteria *(mandatory)*

- **SC-2101**（FR-2101）: e2e: どのモードでもスライダーは「変貌」1 本で、最初は 0.5。光の形・主役の大きさ・長方形の数は出ない
- **SC-2102**（FR-2102）: unit: 変貌 0 の絵は元の写真（モードによらず）。0.5 は今の画素の記録と同じ。0.25 では、写真から 0.5 の絵への変わり方のうち、主役の外のほうが主役より先へ進んでいる（主役の外が写真のままのモードでは、主役が半分も進んでいないこと）
- **SC-2103**（FR-2103）: unit: どのモードでも 0.75・1 の絵は 0.5 と違う。物の複製・被写体の解体・入れ子では、1 は 0.75 より 0.5 から遠い（矩形の組み替えと主題は、長方形の切り方が少しの変化でまるごと入れ替わり、差が頭打ちになるので数では比べない。激しさは比較画像で見る）
- **SC-2104**（FR-2104）: unit: 同じ写真・作品日時・変貌の値で 2 回描くと同じ画素
- **SC-2105**（FR-2105）: unit: 足した形がそれぞれ出る（写真や作品日時を変えて）。画素の記録を記録し直す
- **SC-2106**: 既存のテスト（消したスライダーのものを除く）がすべて通る
