# Feature Specification: 画面の見直し（PC 前提、版 1.25）

**Feature Branch**: `007-ui-review`
**Created**: 2026-10-13
**Status**: Draft
**Input**: 利用者「デザインスキル（ベストプラクティス的なやつ）でフロントの UIUX を見直していきたい」→ frontend-design スキルで今の画面を点検（[decision.md](decision.md)）→「スマホはいったん考慮しなくていい　PC 前提で再検討」→「続けて」。
言葉は [docs/GLOSSARY.md](../../docs/GLOSSARY.md)（デザインスキル・画面・PC 前提・別の世界／ひとつ戻す／別案）。

方向: **画面は暗室の壁、色は作品だけ。** 画面の部品は無彩色にし、目立たせる操作は「別の世界」ひとつにする。絵がいつも画面の中で一番大きく、全体が見える。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 絵がいつも全体で見える (Priority: P1)

パソコンの画面（1280×720 以上）でアプリを開き、写真を入れる。絵は画面の高さに合わせて大きく描かれ、ページ全体はスクロールしない。
スライダーを動かしても書き出しを押しても、絵は同じ場所に見えたまま。

**Acceptance Scenarios**:
1. **Given** 1280×720 で写真を入れる, **Then** 絵の全体が画面の中にあり、ページはスクロールしない
2. **Given** 1440×900, **Then** 絵は 960×720 より大きく描かれる（余白が大きく余らない）
3. **Given** パネルが画面より長い, **Then** パネルの中だけがスクロールする

### User Story 2 - 写真の入れ方がすぐわかる (Priority: P1)

写真を選ぶ前、絵の場所に「写真を選ぶ」と「ここへドラッグ」が出る。クリックでもドラッグでも写真が入る。写真を入れた後は、絵の下の「別の写真」かドラッグで入れ替えられる。

### User Story 3 - よく使う操作が先にある (Priority: P1)

パネルは上から、名前と版 → 世界 → 別の世界・ひとつ戻す → 調整（スライダー）→ 書き出し・レシピの保存 → 詳しい設定（作品日時・レシピの読み込み）。
「別の世界」が一番目立つ。キーボードでも Space で別の世界、Ctrl+Z でひとつ戻す。

### User Story 4 - 言葉と手応え (Priority: P2)

ボタンや案内は使う人の言葉で書かれ、描いている間だけ進み具合が出る。絵の上は囲めることがカーソルでわかる。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-701 配置**: パソコンの画面を対象にする（1280×720 以上。スマホはいったん対象外）。画面の高さちょうどに収め、ページ全体はスクロールしない。
  左に絵の場所、右に操作パネル（幅 320px）。パネルは中だけスクロールする。絵は 4:3 のまま、絵の場所の幅と高さの両方に収まる一番大きい大きさで出す
- **FR-702 写真の入れ方**: 写真を選ぶ前は、絵の場所に「写真を選ぶ」（クリックでファイルを選ぶ）と「ここへドラッグしても入ります」を出す。
  写真のファイルを絵の場所へドラッグして置くと読み込む（写真を入れた後も同じ）。ブラウザの既定のファイル欄（「Choose File」など）は見せない。
  写真を入れた後は、絵の下に写真の名前と大きさ、「別の写真」ボタンを出す。ファイル名は 1 回だけ出す
- **FR-703 パネルの順番**: 上から ① 名前「paraller」と版 ② 世界の選択と、選んだ世界の一行の説明 ③ 「別の世界」（パネルの幅いっぱい、一番目立つ）・「ひとつ戻す」・「別案 N」
  ④ 調整のスライダー 5 本 ⑤ 「2400×1800 で書き出す」・「レシピを保存」・状態の文 ⑥ 「詳しい設定」（閉じた状態で始まる。見出しに作品日時を出す。開くと作品日時の入力・タイムゾーン・現在に合わせる・レシピを読み込む）
- **FR-704 絵についての案内は絵の下**: 写真の情報・部品の状態・囲みの案内・囲みを消す・読み込みの注意と失敗の理由は、絵の下に出す。
  案内の文はパネルの本文より小さく控えめな色にする（失敗の理由は失敗の色）
- **FR-705 言葉**: 「直前のレシピ」→「ひとつ戻す」、「別案番号 0」→「別案 0」。世界の選択肢は短い名前だけ（括弧を入れ子にしない）にし、説明は選択の下に一行で出す。
  レシピの読み込みはボタン「レシピを読み込む」と、その下の控えめな注意「同じ写真を先に入れてください」
- **FR-706 色と文字**: 画面の部品（背景・パネル・ボタン・スライダー・線）は無彩色（R=G=B）にする。色を持つのは絵と失敗の文だけ。
  文字は端末のフォント（外部のフォントは読まない）で、大きさは 3 段（名前 20px・本文 14px・補足 12px）。控えめな文字も背景との明るさの比 4.5 以上
- **FR-707 手応え**: 進み具合のバーは描いている間だけ出す。描いている間、絵を少し暗くする（終わると戻る）。写真がある間、絵の上のカーソルは十字にする。
  書き出しの「キャンセル」は書き出している間だけ出す
- **FR-708 キーボード**: Space で「別の世界」、Ctrl+Z（Mac は ⌘Z）で「ひとつ戻す」。文字入力・選択・スライダー・ボタンに選択枠があるときは奪わない。
  キーボードで選んだ部品には見える選択枠（2px 以上）を出す。ボタンにキーを小さく添える
- **FR-709 動きを減らす**: 端末の「動きを減らす」設定のときは、絵を暗くする切り替えの動きをなくす
- **FR-710 変えないもの**: 描かれる絵・レシピ・部品・囲み・書き出し・外部通信 0 件・端末内処理は変えない（同じ写真・設定で同じ絵）。版は 1.25 にする

### Out of Scope

- スマホ・タブレットの画面（いったん考えない。利用者 2026-10-13）
- これまでの世界の一覧（クリックで戻れる小さな絵の列）。機能の追加なので、あとの仕様で扱う

## Success Criteria *(mandatory)*

- **SC-701**（FR-701）: 1280×720 と 1440×900 で写真を入れると、ページの高さが画面の高さ以下で、絵の全体が画面の中にある。
  パネルは絵より右。1440×900 では絵の表示が 960px より広い。1280×720 では絵の表示の高さが画面の高さの 70% 以上
- **SC-702**（FR-702）: 写真を選ぶ前、絵の場所に「写真を選ぶ」が見え、ファイル欄は見えない。ファイルを絵の場所へドロップすると読み込まれる。読み込み後に「別の写真」がある
- **SC-703**（FR-703）: パネルの中で、世界 → 別の世界 → スライダー → 書き出しの順に上から並ぶ。作品日時の入力は最初は見えず、「詳しい設定」を開くと見える
- **SC-704**（FR-704, FR-705）: 部品の状態・囲みの案内は絵の下にあり、文字は 13px 以下。「直前のレシピ」という言葉はない。「ひとつ戻す」がある。世界の選択肢に「（」が 2 つ以上のものはない
- **SC-705**（FR-706）: 画面の背景・パネル・ボタン・「別の世界」の色が R=G=B。控えめな文字とパネルの明るさの比が 4.5 以上
- **SC-706**（FR-707）: 描き終わると進み具合のバーは見えない。写真がある間、絵の上のカーソルは十字。書き出していない間「キャンセル」は見えない
- **SC-707**（FR-708, FR-709）: Space で別案が 1 増え、Ctrl+Z で戻る。スライダーに選択枠があるときの Space では変わらない。キーボードで選んだボタンの選択枠は 2px 以上。動きを減らす設定で切り替えの時間が 0
- **SC-708**（FR-710）: 既存のテスト（世界・部品・囲み・主題・Phase 9 の再現・書き出し・外部通信 0 件・file://）はすべて通る。版は 1.25

## Assumptions

- 作品日時は seed に使うので残すが、普段は触らないので「詳しい設定」に入れる（見出しに今の作品日時を出し、隠れても何の日時で描いているかはわかる）
- レシピの保存は気に入った絵を残すのに使う（CLAUDE.md「気に入った絵は再現できるようにする」）ので、詳しい設定に入れず書き出しの隣に置く
- 書き出しの大きさの文字「2400×1800」は、何が出るかがわかるので残す
