# Feature Specification: paraller — 空間モードだけのシンプルなアプリ（版 1.24）

**Feature Branch**: `006-paraller`
**Created**: 2026-10-13
**Status**: Draft
**Input**: 利用者「モード自体が今の奴だけでよくね？」「変貌世界っていう名称も変えたい」→「parallerにしよう paraller 1.24 とか ver書いておけ」「モードは削除で シンプルにしてほしい」。
きっかけ: アプリを開くと最初のモード「変貌世界」（world-v3）が出て、利用者が今回の絵（空間モード）と取り違えた（[docs/GLOSSARY.md](../../docs/GLOSSARY.md)）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 開いたらすぐ今の世界が使える (Priority: P1)

アプリ（paraller）を開くと、最初から空間モードの画面で、モードの切り替えはない。名前と版（ver 1.24）が見える。写真を選ぶと、世界（主題・矩形の組み替えなど）がすぐ描かれる。

**Acceptance Scenarios**:
1. **Given** アプリを開く, **Then** 見出しとタブの名前が「paraller」、版「ver 1.24」が見え、モードの切り替えはない
2. **Given** 写真を選ぶ, **Then** 空間モードの絵が描かれ、世界・スライダー・囲み・書き出し・レシピが使える

### User Story 2 - 古い作品のレシピ (Priority: P2)

以前のモード（world-v3・reference-v1・space-v1）で保存したレシピを読み込むと、再現できない理由が出る（別の絵を描かない）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-601**: アプリの名前を「paraller」にする（画面の見出し・ページの名前・書き出しのファイル名の頭）。版を「ver 1.24」と見出しの横に出す。版は `package.json` の version（1.24.0）から取り、
  利用者に渡すたびに上げる（1.24 → 1.25 → …）
- **FR-602**: モードは空間（space-v2）だけにする。モード「変貌世界」（world-v3）と「基準再現」（reference-v1）は、画面・コード・テスト・道具から削除する
  （git の履歴には残る）。001 の仕様（docs/SPEC.md の基準再現 A01 など）のうち、この 2 つのモードに関わるものは取り下げる
- **FR-603**: 画面は、写真・作品日時・空間（世界・別の世界・別案番号・直前のレシピ・スライダー・囲み・部品の状態）・書き出し・レシピだけにする。
  古いモードだけの欄（分解の細かさなどのスライダー・構成のリセット・元画像と比較・診断表示・見た目の比較・モードの切り替え）はなくす。
  書き出しの品質の選択（標準／高品質 3×3）もなくす（空間モードでは効いていなかった。実装中に確認、2026-10-13）
- **FR-604**: world-v3・reference-v1・space-v1 のレシピは読み込まず、「以前のモードの作品です。このアプリでは再現できません」と理由を出す
- **FR-605**: 空間モードの絵・レシピ・部品・囲み・外部通信 0 件・端末内処理は変えない（同じ写真・設定で同じ絵）

## Success Criteria *(mandatory)*

- **SC-601**（FR-601）: 見出しとページの名前が「paraller」、「ver 1.24」が見える（版は package.json と一致）。書き出しのファイル名は「paraller-」で始まる
- **SC-602**（FR-602, FR-603）: 開いた直後から空間の欄が見え、モードの切り替え・古いモードの欄はない。写真を選ぶと描かれる。
  `src` に world-v3・reference-v1 の描画・構成・プリセット・比較シートのコードがない
- **SC-603**（FR-604）: world-v3・reference-v1 のレシピを読み込むと理由が出て、絵は変わらない
- **SC-604**（FR-605）: 空間モードの既存のテスト（世界・部品・囲み・主題・Phase 9 の再現・外部通信 0 件）はすべて通る。単一 HTML を file:// で開いて描け、通信 0 件

## Assumptions

- 時刻（作品日時）は空間モードの seed に使うので残す
- 書き出しの大きさ（2400×1800）は空間モードのまま。レシピの output.qualityMode は互換のため残す
